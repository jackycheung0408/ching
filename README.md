# 成渝吃貨局作戰室

5位型男的成都 × 重慶 6天5夜行程作戰室。09/10（四）— 09/15（二），單頁網頁工具，開了就能直接用。

🔗 線上網址：https://jackycheung0408.github.io/ching/

## 這頁能做什麼

- **時間軸**：每天的行程按站排列，飛機／高鐵／退房這種真正卡死的時間會標「必達」，其他行程用「第N站＋預估時長」呈現，不寫死鐘點。
- **現場延後**：每天上方有 −15/−30/+15/+30/+60 按鈕，行程臨時delay時點一下，後面所有行程自動順移；如果會撞到必達時間，卡片會跳出紅色警告。
- **臨時換地點**：每天底部「口袋名單」抽屜，放願望清單裡還沒排進行程的備案，可以直接點開高德地圖。
- **口碑資訊**：部分景點/餐廳附上大眾點評、攜程等來源查到的評分與評價重點（💬標示）。
- **已完成打勾**：每個行程可以勾選「已完成」，存在瀏覽器裡，換裝置不會同步。
- **落地前 checklist**：證件、行動支付、導航、叫車、高鐵票、網路、重慶地形等出發前提醒。

## 怎麼更新行程

打開 `index.html`，行程資料都寫在檔案底部 `<script>` 裡的 `DAYS` 這個陣列，每一天一個物件，`items` 是當天的行程清單。改完直接存檔、commit、push 就會更新到 GitHub Pages（通常 1-2 分鐘生效）。

`BACKUP` 陣列是口袋名單，依城市分組。
